# MyTravelPay

Веб-форма первого этапа воронки оплаты иностранным поставщикам (MyTravelPay / Мой Агент).

## Что делает

Партнёр указывает сумму счёта и сразу видит предварительный расчёт в рублях:

`сумма / (1 − комиссия МА) × курс + банковский сбор`

Банковский сбор: 0,2% от суммы платежа, минимум 3 000 ₽, максимум 18 400 ₽.

Курсы подтягиваются с BCC FX (Банк ЦентрКредит), с запасным источником ЦБ РФ.

Заявки сохраняются локально в `data/payment-requests.jsonl` (на Vercel — только в runtime memory/logs; для продакшена нужен внешний storage).

## Запуск

```bash
npm install
npm run dev
```

Откройте [http://localhost:3000](http://localhost:3000).
